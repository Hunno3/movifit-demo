# MoviFit - simulacao de login

Previa publica de UX com duas contas ficticias. Nao autentica usuarios reais e nao solicita senha, e-mail, video ou dado pessoal.

Escolha Ana ou Bruno, guarde a opcao de rascunho e use Testar situacoes para experimentar expiracao, falta de conexao e saida em varias janelas.

Este repositorio contem apenas a simulacao estatica; codigo principal, banco e servicos do aplicativo ficam separados. Nao utiliza Auth0, Google, IA ou servico pago. Nao e a versao de producao do MoviFit.
